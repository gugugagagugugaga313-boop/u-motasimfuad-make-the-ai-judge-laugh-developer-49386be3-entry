Entry for [Make the AI Judge Laugh: Developer Excuses](https://make.fun) — write one funny single-line excuse a developer gives when code breaks in production, under 200 characters.

## The entry

`main.py` writes one fixed line to `/output/entry.txt`:

> Prod didn't break because of my code — the agent followed AGENTS.md perfectly, and AGENTS.md was the bug.

## How it runs

```sh
python3 main.py
```

No network, no randomness, no clock. Two runs produce byte-identical output (105 characters, valid UTF-8).
